功能

推广链接需要的，都在这里

不只是把长链接变短。从创建、分流到分析，一个后台搞定。

按国家 / 地区分流

同一个短链接，中国访客去国内落地页，北美访客去英文站，其他地区走默认地址。规则可视化配置，还能模拟任意国家的跳转结果。

实时访问分析

访问趋势、独立访客、来源、国家城市、设备与浏览器、活跃时段热力图，并与上一周期对比。

精准来源追踪

为每个投放站点生成带 ?src= 的链接，即使对方不发送 Referer，也能分清每次点击来自哪里。

全球边缘，就近跳转

部署在 Cloudflare 全球数百个节点，访客从最近的节点完成跳转，统计写入在后台异步完成。

安全的管理后台

签名 Cookie 会话、Turnstile 人机验证防暴力破解；自动识别爬虫，统计数据更干净。

零成本运行

只用 Workers 和 D1，Cloudflare 免费额度每天可处理 10 万次请求，个人和小团队基本不花钱。

工作方式

三步，从链接到洞察

创建短链

自定义后缀或自动生成，可以先建短链、之后再填推广地址，设置有效期和参数透传。

配置跳转规则

设置默认地址，再为不同国家 / 地区指定专属落地页，同一个国家只属于一条规则，不会冲突。

投放并分析

为每个渠道生成投放链接，在后台实时查看访问来源、地区、设备和每条规则的命中情况。

部署

五分钟，拥有自己的短链服务

点击「一键部署」自动创建 Worker 和数据库，或者用命令行手动部署。数据完全保存在你自己的 Cloudflare 账号中。

  • 不需要服务器，不需要维护数据库
  • 表结构在首次访问时自动创建
  • 可绑定自己的域名，例如 go.example.com
一键部署到 Cloudflare
terminal
# 1. 获取代码并安装依赖
$git clone https://github.com/ccvar/cligc_link.git && cd cligc_link && npm install
# 2. 创建数据库，把输出的 database_id 填入 wrangler.toml
$npx wrangler d1 create cligc-link
# 3. 设置后台密码和会话密钥，然后部署
$npx wrangler secret put ADMIN_PASSWORD
$openssl rand -hex 32 | npx wrangler secret put SESSION_SECRET
$npx wrangler deploy
常见问题

你可能想知道

真的免费吗？

代码以 MIT 协议开源，可以免费使用、修改和商用。运行在你自己的 Cloudflare 账号上，Workers 免费版每天 10 万次请求、D1 免费版 5 GB 存储，绝大多数场景用不完。

访客的地区是怎么判断的？

使用 Cloudflare 根据访客 IP 给出的国家 / 地区代码，无需额外的 IP 库。香港、澳门、台湾可以单独设置规则。

为什么推荐用 ?src= 区分来源？

很多网站和 App 不发送 Referer，只看 Referer 会把大量访问记成"直接访问"。为每个投放渠道使用不同的 src 参数，来源统计会准确得多。

数据存在哪里？

短链和访问记录都保存在你账号下的 D1 数据库里，可以随时导出 CSV。项目本身不收集、不上报任何数据。
